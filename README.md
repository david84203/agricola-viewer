# 農家樂 Agricola 卡牌圖鑑

農家樂（Agricola）繁體中文化卡牌視覺化瀏覽器。

## 功能
- 📋 629 張卡牌完整資料（次要發展卡 + 職業卡）
- 🖼️ 從原始 9 格圖自動裁切顯示對應卡片圖像
- 🔍 即時搜尋（牌名、說明、卡片ID）
- 🎛️ 依類型篩選（次要發展卡 / 職業卡 / 雙色卡）
- 📦 依牌組篩選（A, B, C, D, E, AY...）
- 🌙 暗色主題

## 部署
直接部署到 Vercel（靜態網站）。

## 重大更新專區維護

首頁的重大更新讀取 `updates.json`（新的放最前面，date 格式 YYYY-MM-DD）。
重大功能上線時請在開頭加一筆：新功能模式、全站系統改動、重要工具才寫；
小 bug 修正、介面微調、新增卡牌（不論張數）不寫。
文案面向一般使用者，講「對使用者的影響」，不寫技術細節。
